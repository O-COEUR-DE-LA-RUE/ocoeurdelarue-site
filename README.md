# ocoeurdelarue.org

Site de l'association O Cœur de la Rue, hébergé sur Cloudflare (Worker `ocoeurdelarue-site`).

## Mettre en ligne

```bash
cd ~/Sites/ocoeurdelarue-site
npx wrangler deploy
```

Toujours déployer depuis ce dossier à jour : Cloudflare remplace le site entier à chaque mise en ligne.
